# Original game brief

The following is the user's original prompt, preserved before design and implementation.

> I want you to make me a modernized horror game take on oregon trail, it should be like you get a party, you manage members, they might get into fights disagreements, you might run into combat scenarios, we should come up with some kind of apocalyptic alternate universe scenario though where the sky is turning blood red which is why you're migrating. You need to start off by buying supplies. The core pillar of the design is that resources are always toght and there are constant hazards out in the world or people trying to trick and take advantage of you, but there are also people who genuinely need help, but you can't just stop for anything you need to constantly be making forward progress else you'll be consumed by the great haze.

Setup instruction: create the Dream Engine project and GitHub repository and provide the link before beginning real game work.

Working title: **The Great Haze**. No additional setting, mechanics, or art direction has been finalized.
